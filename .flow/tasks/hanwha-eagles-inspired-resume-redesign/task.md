# Task: Hanwha Eagles inspired resume redesign

## Goal

기존 단일 페이지 이력서를 검정 베이스와 주황 포인트의 스포츠 에디토리얼 레이아웃으로 재구성해, 로고 없이도 한화 이글스를 떠올릴 수 있는 강하고 유니크한 첫인상을 만든다.

## Scope

- 검정·오렌지·아이보리 중심의 컬러 시스템 적용
- 전광판, 유니폼 넘버, 경기 기록표를 연상시키는 레이아웃과 타이포그래피 적용
- 히어로, 섹션 인덱스, 경력 타임라인, 프로젝트 카드, 역량 및 연락처 구성 재설계
- 데스크톱·모바일·인쇄 레이아웃과 접근성 유지

## Non-goals

- 한화 이글스 로고, 마스코트, 선수 이미지 또는 상표 그래픽 사용
- 실제 이력서 콘텐츠 작성
- 배포, 커밋 또는 푸시

## Acceptance criteria

- [x] 전체 화면이 검정 베이스와 주황 포인트의 일관된 시각 체계를 사용한다.
- [x] 로고 없이 스포츠 팀·전광판 무드가 느껴지는 독자적인 레이아웃을 제공한다.
- [x] 여섯 개 이력서 섹션과 데이터 기반 렌더링이 그대로 동작한다.
- [x] 390px 모바일 화면에서 가로 스크롤 없이 읽을 수 있다.
- [x] 키보드 포커스, 충분한 대비, reduced-motion 및 A4 인쇄 규칙을 유지한다.
- [x] 정적 검증과 브라우저 QA를 통과한다.

## Constraints and risks

- 특정 구단의 공식 로고나 상표 요소는 사용하지 않는다.
- 어두운 화면에서도 장문 이력서의 가독성이 떨어지지 않아야 한다.
- 기존 `resume-data.js` 교체 방식과 안전한 링크 렌더링을 보존한다.
