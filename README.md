# Resume Portfolio

채용 담당자가 짧은 시간 안에 핵심 경력과 프로젝트를 훑을 수 있도록 만든 단일 페이지 이력서입니다. 빌드 도구나 외부 패키지 없이 동작하며 GitHub Pages에 그대로 배포할 수 있습니다.

## 실제 이력서로 바꾸기

모든 개인 콘텐츠는 `resume-data.js`에 있습니다. 이력서 파일을 바탕으로 아래 항목을 교체하면 화면과 인쇄본에 함께 반영됩니다.

1. `profile`: 이름, 직무, 소개, 위치와 희망 조건
2. `proofPoints`: 경력 연차, 프로젝트 수처럼 첫 화면에서 보여줄 핵심 수치
3. `links`: 이메일, GitHub, LinkedIn 등 연락처 (`href`가 비어 있으면 링크가 노출되지 않습니다)
4. `experience`: 경력과 성과
5. `projects`: 대표 프로젝트와 링크
6. `skills`, `education`, `credentials`: 기술, 학력, 자격
7. 마지막 검수 후 `isTemplate`을 `false`로 변경

선택 항목의 배열을 비워 두면 해당 섹션과 탐색 링크가 자동으로 숨겨집니다. 텍스트에는 HTML이 아니라 일반 문자열만 넣어 주세요.

## 로컬에서 보기

저장소 루트에서 정적 서버를 실행합니다.

```powershell
python -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다. 파일을 직접 더블클릭해도 기본 화면은 동작하지만, 배포 환경과 같은 조건으로 확인하려면 정적 서버 사용을 권장합니다.

## 검증

Node.js가 설치되어 있다면 다음 명령으로 문서 구조, 콘텐츠 모델, 반응형·접근성·인쇄 규칙을 확인할 수 있습니다.

```powershell
node scripts/validate.mjs
```

## 인쇄와 PDF

상단의 `PDF / 인쇄` 버튼을 누르면 A4용 레이아웃으로 전환됩니다. 브라우저 인쇄 창에서 대상을 `PDF로 저장`으로 선택하면 별도 파일을 만들 수 있습니다.

## 배포

현재 작업에는 배포 설정이 포함되어 있지 않습니다. GitHub Pages를 사용할 때는 저장소 설정에서 배포 소스를 선택한 뒤 루트의 `index.html`을 서비스하면 됩니다.
